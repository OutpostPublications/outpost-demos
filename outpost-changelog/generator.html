Using it in Ghost: in the editor type /html, paste, and click away; the card previews right in the editor. The changelog post is both the web page and the email, and these blocks render fine in both; if you'd rather keep the web changelog on native lists, set the card's visibility to email only and keep a native copy for web. House rules enforced here: no em dashes, brand hex values baked in (Outpost purple #8340B9, category chip colors listed in the mockup). This is a proof of concept; the same single file can move to any static host later, unchanged.
